# 个人视觉方向提案

独立预览路径：`/visual-study/`。本轮仅供用户确认视觉方向，不替换现有首页。

- 暖色关系：暖红、柔绿、淡粉、浅黄、灰蓝，以米色承接。
- 冷色关系：灰蓝、淡粉、浅黄、柔绿，以浅灰米色承接。
- 同一版式切换色彩；项目判断可展开，便于评估实际文字排版。
- 首屏几何构成是色彩研究，不是产品界面。项目图为用户录屏中的原界面，CSS 隐藏系统状态栏，无硬件框。
- 文案为视觉排版示例，尚待用户确认；完整网站的本地改稿继续保留，不在本轮发布。

## 方向 02

预览路径：`/visual-study-02/`，仅发布一个首屏与可展开的项目摘要。

- 色彩直接用于页面分区，移除几何插画。
- 浅蓝、淡粉、浅黄、柔绿背景；红色强调。
- Noto Sans SC / Noto Serif SC 自托管 WOFF2，页面可切换标题字体。
- 字体依据本页文案生成子集，改文案需更新子集；原字体来自 Google Fonts，OFL 许可随预览提供。
- 当前作品集首页和上一版视觉提案保持原样。
