# 刷牙主题产品单页

入口：`/brushing-case/`。`/case-storyboard/` 转到此版本，并映射旧锚点。

## 本轮修改

- 改名为“小乐好习惯养成方案”，明确 3–6 岁家庭；移除参与阶段和含糊的使用成本说法。
- 展示“看动画 → 出现任务 → 家长确认 → 玩偶提醒 → 孩子实际刷牙 → 家长记录 → 后续继续提醒”的完整过程。
- NFC 是独立支路，不以创建家长任务为前提；每集从 10 个启发问题中选择一个作为起点。
- 家长任务原型直接通过 Shadow DOM 嵌入单页，没有跳页或 iframe；绑定设备为演示前提。
- 角色动作依据用户提供的产品照片参考生成，原图留在 `/workspace/generated_images/`。触卡过程为网页 CSS 动态示意，不是实机视频。
- 触卡与家长聊天记录并排显示；聊天区沿用用户提供界面的绿色/浅绿气泡、头像与布局。十个问题及对应回复均明确标注为重构示例，非真实儿童记录。
- 卡片正反面为原型，按拟定的 85.6×54mm 尺寸提供打印样式，不声称是历史实物尺寸。
- 实际刷牙仍需家长核验；对话不自动添加或完成任务，今日完成不会结束重复目标。
- 刷牙动画视频素材尚待提供，目前明确保留占位。原访谈说明放在资料展开区，正文署名“蛋蛋妈妈访谈”，不展示时间戳。
- 附件延用此前重构材料，待本单页内容确认后再同步修订附件。

本地 40 项检查通过，覆盖同页原型状态、刷牙主题、触卡/聊天联动、十题示例轮换、家长核验、目标编辑、手机状态、卡片打印尺寸和 320–1440 像素布局。

- 撤下未获确认的生成角色、卡片及其打印入口，使用占位；不再擅自重画或发布新设计。
- 优先复用用户原图，允许裁切、抠背景和排版；三种原角色动作应分配到首屏、流程和空状态。

- 删除聊天区装饰音频/复制图标与重复小字，流程改为“一起看动画”。
- 正文统一可读字体层级，正文 16px，辅助文字原则上不低于 13px；原型内的关键文字同步放大。
