# 产品单页图文排版预览

预览路径：`/case-storyboard/`。

本轮只审阅布局，不引入新视觉风格。图片、视频、NFC 卡片和复杂互动保留清楚标注的占位，未替换原作品集首页。

阅读顺序：产品与职责 → 使用障碍与研究依据 → 家长/孩子双路径 → 原型与 NFC 动态演示位置 → 完成依据 → 交付与验证。

- 家长与孩子的路径共享主题，各自独立触发。
- NFC 从该集 10 个预设启发问题中选择一个作为对谈起点，仍按规划呈现。
- 原型占位链接到现有任务设置审阅页，视频占位不嵌入手机录屏。
- 默认呈现整页布局，可开启“编排说明”查看图文分工。
- 当前字体依据本页字符生成子集，修改文案需更新子集。OFL 许可随字体提供。
