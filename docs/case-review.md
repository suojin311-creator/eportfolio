# 成长包单页与任务界面审阅

独立预览路径：`/case-review/`。保留第一版站点视觉基调，仅审阅本产品，不涉及个人首页。

- `#task-design`：按原小程序浅绿背景、白色圆角卡片、绿色主按钮重构的任务设置与列表。
- 支持动画入口、模拟动画结束、推荐任务一键确认或调整计划、保存、编辑、家长核验今日完成。
- 单日记录与整个重复目标的生命周期分开；同名目标再次添加更新设置，不生成重复目标。
- 平面模式不带状态栏；手机模式使用 09:41、正常信号和绿色满电。
- 设置界面、推荐弹层和添加后列表均标记为重构；原界面参考可对照。
- `#copy`：项目详情文案的七组删改对照。证据边界、NFC 规划和参与阶段保留，未知上线成绩不填。
- 原型只在本页内存操作，不连接真实设备或保存用户数据。
- 字体为 Noto Sans SC 自托管字符子集，许可随预览；改文案需更新子集。

本地浏览器检查通过：输入校验、提醒开关、计划保存/编辑/去重、推荐承接、家长核验、标签键盘操作、原界面对照与焦点恢复、两种展示模式、320–1440 像素布局和附件访问。
